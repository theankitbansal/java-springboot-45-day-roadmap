# Coding Exercises

Exercises should be solved in small, runnable programs. Prefer Java 8-compatible syntax while learning core Java.

## Rules
1. Attempt the problem before viewing a solution.
2. Include sample input/output or explain test cases.
3. Test normal, boundary, and invalid cases.
4. Explain the approach and time/space complexity when relevant.
5. Commit working solutions with clear messages.
6. Use synthetic banking examples only.
